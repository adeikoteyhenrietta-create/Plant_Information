# Plant Information
A Python program that shows how INHERITANCE works in object-oriented programming.

# What it does
You type in plants and flowers one line at a time and type `-1` when you're done. 
The program stores them all in a list called `my_garden`, then prints the details of each one.

A FLOWER is a type of PLANT, so it has everything a plant has (name and cost), plus whether it's annual and the colour of its flowers.

# Error handling
If a line is wrong, the program prints a short error message, skips that line and keeps going.
